# Security

keylime runs entirely in your browser and has no server, so there is no user data to leak. Its in-page website is still meant to verify passkeys properly, so we treat a bypass as a real bug.

**If an attack gets through, or a check passes when it shouldn't,** report it privately with GitHub's [private vulnerability reporting](https://github.com/Primitivelabai/keylime/security/advisories/new). Include the browser, the device or authenticator, and the steps.

We'll reply within a week. keylime is a teaching tool: please don't use its relying party code to protect a real service.
